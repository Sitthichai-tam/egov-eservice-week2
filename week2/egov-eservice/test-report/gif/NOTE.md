# GIF ของ TC ระดับ P1 (ครบ 43 ข้อ)

TEST-PLAN มี TC ระดับ P1 จำนวน 43 ข้อ แต่ละ GIF อัดจากการรัน TC นั้นทีละข้อ (`playwright test -g "<TC>"`) กับเว็บที่ `TEST_MODE=1` ไม่ตั้ง BUG_MODE ทุกข้อผ่าน (`1 passed`) ผลของแต่ละข้ออยู่ใน `summary.txt`

## 2 แบบของ GIF

**40 ข้อ: วิดีโอหน้าเว็บจริง** อัดด้วยตัวครอบ `app/e2e-gif/hook.js` ที่ฉีดการอัดเข้าทุก `browser.newContext()` ไม่ได้แก้ไฟล์เทสต์ เทสต์หนึ่งข้อสร้างเบราว์เซอร์หลายตัว หลายตัวเป็นหน้าว่าง GIF ใช้เฉพาะวิดีโอที่มีภาพ (> 8 KB) ต่อกัน ตัดที่ 45 วินาที

**3 ข้อ: บันทึกการเรียก API จริง** (ไม่ใช่วิดีโอหน้าเว็บ): `TC-PAY-02`, `TC-PAY-03`, `TC-PDPA-02` เพราะเทสต์ 3 ข้อนี้ตรวจผ่าน API ไม่มีหน้าเว็บให้อัด (PAY-02 ไม่เปิดเบราว์เซอร์เลย, PDPA-02 วิดีโอว่าง) จึงรันเทสต์จริงด้วย `DEBUG=pw:api` เก็บบรรทัดคำขอ (→) และผลตอบกลับ (←) ตามลำดับเวลาจริง แล้วเรนเดอร์ทีละบรรทัดเป็น GIF (`app/e2e-gif/render-api-gif.js`) บรรทัดสุดท้ายคือผลของ Playwright (`1 passed`) ตัดบรรทัด header ออกเพื่อให้อ่านง่าย ไม่ได้แต่งเนื้อหา

## ข้อจำกัด
- ตรวจด้วยตาแล้ว: TC-AUTH-01 (หน้า login), TC-DOC-01 (หน้าคำขอพร้อมเอกสาร), TC-PAY-02 (เฟรมสุดท้าย) ไฟล์อื่นตรวจจากขนาดและจำนวนเฟรม ไม่ได้เปิดดูทีละไฟล์
- รอบแรก 7 ข้อได้ GIF ว่างเพราะสคริปต์เอาวิดีโอว่างมาต่อด้วย แก้แล้ว (6 ข้อเป็นวิดีโอจริง, PDPA-02 เป็นบันทึก API)
- บางไฟล์ภาพสั้นมาก (5–6 เฟรม) เพราะหน้าเว็บเปิดชั่วครู่ในเทสต์นั้น
- GIF รวม ~20 MB ถ้าที่ส่งงานจำกัดขนาด ต้องลดความละเอียดหรือจำนวน
